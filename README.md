# springboot Training
- springboot 学習用リポジトリです。

## 学習方針
単にコードを動かすだけでなく、なぜその設計にするのか
- なぜその設計を採用するのか
- 例外や異常系をどのように扱うのか
- 保守性・可読性をどのように確保するのか  
を考えながら学習・検証を行っています。

## 目的
- springboot の基礎構文の習得

## ディレクトリ構成
```text 
springboot/
```
## 学習内容
- springboot 基本文法
- springMVC 

## 実行方法
```text 
./mvnw spring-boot:run
```

## 開発環境
- OS : Linux(Ubuntu 24.04 LTS)
- 言語 : Java 17
- フレームワーク : SpringBoot 3.5.6
- ビルドツール : Apache Maven 3.8.7
- スクリプト : Shell Script (Bash)
- バージョン管理 : Git / GitHub
- 開発ツール : VS Code
